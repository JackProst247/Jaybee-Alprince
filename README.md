# JayBee.B & Alprince Macaraeg Igne

Романтик минимал дурсамжийн галерей.

- `index.html` — 3D галерей: хоёр дүр хамт алхаж зургуудыг ханан дээрээс үзнэ (WASD / сум / joystick, зураг дээр дарж томруулна, "Аялал" товчоор автоматаар алхуулна).
- `grid.html` — энгийн минимал галерей.
- `img/` — бүтэн хэмжээтэй зургууд, `tex/` — 3D-д зориулсан хөнгөн хувилбарууд.

GitHub Pages-ээр шууд ажиллана (Settings → Pages → main / root).
